## Two commands and you're in business

```bash
dotnet new install CleanLambdaFunction.Template
dotnet new cleanlambdafunction --name Acme.Reviews --authorName "Your Name"
```

That's a solution with three layers, three test projects, a Dockerfile and a CI pipeline. Now go and tell your team you've been working on it all week.

## What's in the box

<CardGrid>
  <Card title="Lean Mean Clean Architecture" icon="puzzle">
    Presentation, Application and Infrastructure, with one job each. Infrastructure is `internal`, so it can't sneak
    into places it doesn't belong.
  </Card>
  <Card title="Cold starts, but quicker" icon="rocket">
    Source-generated JSON, Mediator and Mapperly mean no reflection when Lambda wakes your function up.
  </Card>
  <Card title="Tested like it matters" icon="approve-check">
    xUnit, Shouldly and a 95% coverage gate. Every test gets its own throwaway SQLite database, so nobody steps on
    anybody's toes.
  </Card>
  <Card title="Runs on your laptop" icon="laptop">
    The container image includes the Lambda runtime emulator. Build it, run it, `curl` it. No AWS account needed until
    you're ready.
  </Card>
</CardGrid>
